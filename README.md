## ✨ Fitur Utama

- 🎧 **Streaming Audio Jernih**: Putar musik tanpa jeda dengan pemutar audio HTML5 dan visualizer gelombang suara.
- 🖼️ **Cover Album HD**: Integrasi otomatis pengambilan cover album resolusi tinggi dari Spotify & iTunes.
- 📜 **Lirik Sinkronisasi**: Lirik berjalan secara real-time yang tersinkronisasi dengan pemutaran lagu dari berbagai sumber terpercaya.
- 📥 **Batch Downloader & 320kbps**: Unduh lagu favorit dalam kualitas audio tertinggi (320kbps MP3).
- 🔄 **Antrean Cerdas & Radio**: Nikmati pemutaran otomatis berdasarkan rekomendasi dan antrean cerdas YouTube Music.
- 📱 **Desain Ramah Mobile**: Dioptimalkan khusus untuk kenyamanan pengguna di smartphone maupun desktop.

## 🚀 Cara Menjalankan (Development)

1. **Clone repository ini** atau unduh sebagai ZIP.
2. **Install dependensi**:
   ```bash
   npm install
   ```
3. **Jalankan server development**:
   ```bash
   npm run dev
   ```
4. Buka `http://localhost:3000` di browser Anda.

---

## ☁️ Deployment di Vercel

Aplikasi ini sudah dikonfigurasi agar siap 100% berjalan di **Vercel App**:
1. Hubungkan repository GitHub Anda ke Vercel.
2. Build Command otomatis: `npm run build`
3. Output Directory: `dist`
4. Selesai! Aplikasi siap diakses secara online.
